# binayadahal7.github.io

A simple GitHub Pages website starter for the `binayadahal7.github.io` repository.

## Available files

- `index.html` — homepage content
- `styles.css` — visual styling for the page

## Usage

1. Add your personal content to `index.html`.
2. Push the repository to GitHub.
3. GitHub Pages will publish the site at `https://binayadahal7.github.io`.
